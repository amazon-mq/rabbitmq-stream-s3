# TLA+ Models

This directory contains formal specifications for key protocols in the plugin.

## Models

### `osiris-replication/`

Models the Osiris replication protocol extended with the remote tier (tiered storage). Covers writer election, log replication, committed offset advancement, epoch-based truncation, and the upload path with its optimistic lock.

Origin: [rabbitmq/osiris](https://github.com/rabbitmq/osiris/tree/main/tla), dual-licensed under Apache-2.0 and MPL-2.0. Remote tier extensions added in commit [`685fdfe`](https://github.com/amazon-mq/rabbitmq-stream-s3/commit/685fdfe).

Files:
- `OsirisMsgPassing.tla` - the spec
- `MC.tla` - model checking constants (auto-generated by TLA+ Toolbox)
- `MC.cfg` - TLC configuration
- `states/` - saved state traces from previous runs

### `manifest-replication/`

Models the manifest edit replication protocol between the writer and replica nodes. Verifies that sequence-numbered edits, unreliable delivery, and re-sync produce correct replica state under all interleavings.

Files:
- `ManifestReplication.tla` - the spec
- `ManifestReplicationMC.tla` - model checking constants and invariants
- `ManifestReplication.cfg` - TLC configuration

**What it models:**
- A writer producing sequenced edits and broadcasting to registered replicas
- Unreliable channels (arbitrary message loss)
- Replica registration and unregistration (node connect/disconnect)
- Strict sequential application of edits on replicas
- Gap detection and full re-sync from the writer

**Invariants verified:**
- `SeqBounded` - no replica's sequence exceeds the writer's
- `ReplicaConsistent` - any replica in "ok" state holds a valid prefix of the writer's history

**Results:** The state space with the current parameters (2 replicas, 3 edits, 3 epochs, channel depth 2) is too large for exhaustive model checking. Use simulation mode.

## Running

Requires [TLA+ tools](https://github.com/tlaplus/tlaplus/releases) (TLC).

Both models are too large for exhaustive checking with their current parameters. Use simulation mode:

```bash
# Manifest replication model (simulation)
cd manifest-replication/
timeout 3600 tlc -simulate -depth 5000 -workers auto ManifestReplicationMC -config ManifestReplication.cfg

# Osiris replication model (simulation)
cd osiris-replication/
timeout 3600 tlc -simulate -depth 5000 -workers auto MC
```

Simulation mode explores random traces and reports invariant violations immediately when found. Increase the timeout for longer runs. Increase `-depth` for longer traces.
